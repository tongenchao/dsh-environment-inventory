## 一、物理与构图规划（动笔前 · 协议第 1 步）

### 1.1 物理半径比例（单位：史瓦西半径 Rs）

- 事件视界：r = 1.0 Rs（本体，直接不可见）。
- 视界阴影（表观半径）：对无穷远观测者，Schwarzschild 临界曲线的表观半径 = √27/2 ≈ **2.598 Rs**。
- 光子环：位于临界曲线处 ≈ **2.60 Rs**（任务要求"光子环半径约 2.6 倍史瓦西半径"，直接采用）。
  - 视觉取舍：阴影本体画到 **2.52 Rs**，光子环亮线画在 **2.60 Rs**。二者物理上重合于临界曲线，若完全重叠会"黑盘吞掉亮环"，故错开半个环宽做视觉分离（唯一的小偏差，已在代码注释与本文档记录）。
- 吸积盘：内缘 **3.0 Rs**、外缘 **13.0 Rs**。
  - 物理注：非转动 Schwarzschild 黑洞的 ISCO 为 6 Rs；艺术渲染将内缘压缩至 3.0 Rs，让"白热内缘"紧贴光子环形成极端对比（EHT/科普插画通行做法）。此取舍如实记录。
- 背景银河透镜：弱场透镜爱因斯坦半径取 **b_E = 2.9 Rs**，环带紧贴阴影外侧（符合 Sgr A* 模拟观感）。
- 像素换算（1080p）：Rs = 30 px → 阴影 ≈ 78 px、光子环 78 px、盘外缘 390 px、银河环 ≈ 87 px。黑洞系统约占画面宽度的 40%，为宽银幕构图留出空旷星场。

### 1.2 吸积盘倾角与多普勒增亮取舍

- 倾角 i = 22°（盘面法线相对视线）。
  - 大倾角（>45°）：近侧盘会大面积压住阴影、远侧弧线被压平，丢失"光带翻越顶部"的剪影感；
  - 近正对（<10°）：透镜弧与盘的层次感弱；
  - **22° 折中**：远侧盘带清晰地从阴影上方拱过（配合"光带"元素），近侧盘下缘横穿阴影下半部，层次与对比最好。
- 自转：prograde（俯视逆时针），观测者看到**左侧为接近侧**。
- 多普勒增亮：亮度 ∝ (1 − β·cos a)³，β = 0.30（盘轨道速度 ~0.3c 量级）→ 左侧 ≈ 2.2×、右侧 ≈ 0.34×。
  - 颜色取舍：接近侧向白/蓝混合（蓝移），远离侧向暗红混合（红移）——方向与量级符合 Interstellar Gargantua"左亮右暗"的经典观感。
  - 备注：未做完整引力红移与相对论针孔投影建模，属"视觉物理"级别近似。

### 1.3 透镜环的数学近似（背景银河 → 环绕光环）

- 采用**弱场透镜方程的反演映射**：β = b − b_E²·b/|b|²
  - b：屏幕像素到黑洞中心的碰撞参数（Rs 单位）；
  - β：该光线对应的源平面角位置；
  - b < 2.52 Rs：光子被俘获 → 阴影（纯黑）；
  - 2.52 < b < b_E：f < 0，得反演（次级像）区域；
  - b ≈ b_E：所有方向采样到源中心 → 爱因斯坦环。
- 逐像素逆映射：对预生成的"银河源场"（星点 + 星云 + 银河带 + 衍射星芒）做逐像素重采样（最近邻 + 边界钳制），一次性离屏烘焙，**不逐帧计算**。
- 环向拉伸：b < 6 Rs 区域做**切向 3 点采样平均**，把星点沿切向拉成弧（爱因斯坦环的切向畸变）。
- 放大率增强：环附近按高斯包络放大亮度（模拟放大率 → ∞ 的观感），叠加暖色辉光。
- 星芒：源场中给亮星画衍射十字，靠近环时被切向剪切拉长（视觉上"星芒被吸入视界"）。

### 1.4 色调分级

- 吸积盘径向：内缘白热（#f2f6ff，微蓝）→ 亮橙（#ffc06a）→ 橙红（#ff8a2a）→ 暗红（#9c2a0c → #5e1205）→ 外缘深红（#2a0602）——白热与暗红的**极端对比**。
- 光子环：暖白（#fff8e8）+ 琥珀辉光 + 左亮右暗微调 + 微色差（CA）。
- 背景：深空蓝黑（#04060c）+ 蓝/紫/青星云 + 暖色银河带。
- 全局：暗部压黑、四角 vignette、上下 40 px 电影渐变条、胶片颗粒（overlay 噪点）、缓呼吸推镜（±0.6%）。

### 1.5 构图（1920×1080，16:9 宽银幕）

- 黑洞主体居中（960, 540）；银河透镜环紧贴阴影（≈ 2.9 Rs）。
- 吸积盘大椭圆带（13 Rs）横向展开 → 宽银幕拉伸感。
- 光带：自盘带两侧（±4.2 Rs）翻越黑洞顶部（顶点 ≈ −4.6 Rs）。
- 飞船剪影：左下三等分交点附近（0.21W, 0.79H），朝向黑洞，微小尺寸（≈ 70 px），带轮廓光与引擎微光。
- 尘埃/星芒：3.2–13.5 Rs 螺旋吸入，内圈白热、外圈暗红，切向拖尾。
- 前景：颗粒 + 暗角 + 呼吸推镜。

## 二、实现要点（v1.3 定稿）

- **分层离屏预渲染**（resize/初始化时一次性烘焙，逐帧零重算）：
  - `srcField`：程序化银河源场（1050 星点、10 星云团、斜向银河带、衍射星芒）；
  - `lensed`：对 srcField 做逐像素透镜逆映射（β = b − b_E²·b/|b|²）+ 切向 3 点拉伸 + 高斯放大率 + 阴影打洞 + 暖辉光/多普勒冷暖不对称烘焙；
  - `diskFull` / `diskNear`：吸积盘（220 扇区 × **每扇区独立压扁空间径向渐变** × 多普勒 × 远侧压暗；near 版裁掉上半部用于"近侧盘压阴影"）。
- **逐帧动态层**：光子环（轨道热点 + 微色差 + 呼吸脉冲）、翻顶光带（贝塞尔流线 + 双 dash 流动高光）、螺旋吸入尘埃（300 粒子，Kepler 角速度 + 二次方吸入，远/近两侧分两次绘制、阴影夹中间；5% 粒子带透镜剪切星芒）、飞船剪影（轮廓光 + 引擎焰 + 漂移呼吸）、前景颗粒/暗角/电影条。
- 支持 `devicePixelRatio`（上限 2）；`FORCE_8K: true` 切 7680×4320（辅助层自动降采样控内存；8K 逐像素烘焙约 10–20s，适合出片）。
- 首帧**同步渲染**（不等 rAF），headless 截图直接有内容；暴露 `window.__BH__`（`getConfig` / `setMode({force8k})` / `renderFrame(t)` / `reload`）供自动化。
- 动画循环 rAF；`dt` 钳制防跳帧；粒子寿命循环重置。

### 自查出的差距（v1.0 实测）

1. **光带呼吸动画未生效**：`apex` 变量为死代码，贝塞尔控制点写死（v1.1 修复：由顶点反推控制点 Yc）。
2. **首帧尘埃隐形**：`newDust()` 未初始化 `p.r`，第 0 帧 NaN 坐标（v1.1 修复）。
3. **倾角 22° 倾斜感不足**：椭圆压扁仅 0.93，视觉接近正对（v1.1 改为 30°，cos=0.866）。
4. **吸积盘径向色带整体失效（重大）**：v1.0 每扇区用中径 rM 的单一颜色 → 全盘均匀橙，"白热内缘→暗红外缘"缺失；像素断言 L=143/R=139 几乎相等暴露了问题（v1.2 重写为每扇区独立压扁空间径向渐变，6 档 ramp×Doppler×远侧 0.82 压暗）。
5. **左盘外缘被多普勒漂白**：白色混合 w=0.6 无条件叠加，左盘整条变白、暗红外缘消失（v1.3 修复：w×t 按温度衰减，仅内缘白热）。
6. **透镜环与盘区分不明显**（v1.3 将银河光环烘焙外沿 6.0→7.0 Rs，形成独立柔和光晕）。
7. **断言采样几何陷阱**：环形均值把光带顶点/近远侧 boost=1 区计入，造成假 FAIL——修正为水平扇区采样；这是"用像素断言做自查"学到的教训。

## 五、使用说明

- 双击 `index.html` 即运行（file://，零依赖）。
- 出 8K 静帧：打开文件把 `CFG.FORCE_8K` 改为 `true`（或控制台 `__BH__.setMode({force8k:true})`）。
- 自动化：headless 截图可直接出图（首帧同步渲染）；`__BH__.renderFrame(t)` 可驱动指定时刻。
